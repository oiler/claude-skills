## Lens: accuracy

Check every factual claim the spec makes against its source:

- Claims about the codebase: file paths, function and symbol names, line references, current behavior. Open the file.
- Claims about platforms, tools, and libraries: frontmatter fields, CLI flags, API behavior, version numbers. Check the docs the spec cites, or the installed source.
- Survey claims ("X never appears", "all N examples do Y"): rerun the search. A survey claim without its command is itself a finding.
- Quotes of other documents: compare them word for word.
- Contradictions between the spec and the evergreen docs listed under Paths.
