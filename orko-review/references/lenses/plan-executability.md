## Lens: executability

Read each task as the fresh implementer who gets only that task's text:

- File paths, symbols, commands, flags, and versions the task names: check that each exists and is right in the codebase. Run read-only commands to confirm.
- Order and dependencies: a task that needs something a later task creates.
- Steps that assume context the task doesn't give.
- Tasks too large to finish and verify in one pass, or so small they should merge.
- Code in the plan that wouldn't run as written.
