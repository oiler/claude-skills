## Lens: design

Judge whether the approach is the right one:

- Does it solve the problem the spec states, for the user the spec names? Trace each goal to the mechanism that delivers it.
- Is there a simpler approach that meets the same goals? Describe it concretely.
- Scope: parts that serve no stated goal, and goals no part serves.
- Risks the spec doesn't list, and listed risks whose mitigation doesn't mitigate.
- Internal contradictions between sections.
