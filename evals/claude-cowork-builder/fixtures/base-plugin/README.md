# Meeting Notes

Meeting Notes turns the mess you type during a call into something you can actually send to people. Give it your notes — pasted into the chat, or saved in the folder you are working in — and it comes back with the decisions, the action items and who owns each one, and the questions that were raised but never settled. It reads the whole thing first, so the decision that showed up forty minutes in does not get lost.

Nothing needs to be connected for this to work. If you do have a document tool connected in Cowork, it can go and fetch the notes for you instead of asking you to paste them, but that is a convenience rather than a requirement. The finished summary is saved into your working folder with the meeting date in the file name, and you will be told exactly what it is called so you can find it and open it yourself.
