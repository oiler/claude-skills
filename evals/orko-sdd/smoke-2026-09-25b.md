## Defects found

- **D1 (skill doc, minor).** The `SKILL.md:119` harness-refusal note under-describes the refusal. Command substitution, shell variables holding commands, and loops with computed command names are also refused inside an entered worktree, not only `cd`/`git -C` + git. A controller following the note literally hits a refusal on its first `sdd-workspace` call if it captures the path into a variable. Suggested fix: "split any compound, substituted, or looped command into plain single calls".
- **D2 (skill doc, minor).** No named role or effort rule for the final review's scoped re-review (A2). `log` accepted `re-reviewer-security` under `--task final`, so the script allows it, but the text only implies it.
- **D3 (skill doc, minor).** The final-wave text covers out-of-scope observations but not fix-diff Minors (A3), and doesn't reconcile `:38` with `:40` for parked findings that need an oiler decision (A4). The second gap produced visible triple-reporting in the Follow-up section.
- **D4 (report script, cosmetic).** Follow-up's lead line "the final fix wave may have resolved the ones the final review marked must-fix" prints even when the final review marked none must-fix. Deferred minors that were later parked (Task 1's non-ASCII minor → Decided #6) are not deduplicated against Decided.
- **Not a skill defect.** The product shipped a test that fails on Python 3.12+ (Decided #8). It's parked and surfaced; the workflow handled it as documented.
