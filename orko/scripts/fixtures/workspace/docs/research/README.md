# Research

Store durable evidence that informs objectives, decisions, specifications, or roadmap changes. Organize subdirectories when useful—for example `users/`, `market/`, and `technical/`.

Each note should include:

- question and method;
- date collected or checked;
- source and access date;
- findings separated from interpretation;
- limitations and contradictory evidence;
- implications and linked decisions;
- privacy or consent constraints, when applicable.

Do not treat an AI-generated summary as verified evidence without checking its underlying sources.
