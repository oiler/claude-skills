# Product Versions

Each `MAJOR.MINOR/` folder is a product dossier for one minor-version workstream. It may contain multiple patch-release records.

Create a new dossier by copying `0.1/`, then update its metadata, scope, delivery profile, and indexes. Do not move patch releases between minor-version folders after release.
